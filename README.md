# 🩺 DocAppoint - Doctor Appointment Booking System

A modern and responsive doctor appointment booking platform where users can explore doctors, view details, and book appointments easily.

---

## 🌐 Live Website

🔗 Live Link: https://docappoint-client-three.vercel.app/

---

## 🚀 Features

- 🔐 Secure Authentication System (Better Auth)
- 👨‍⚕️ Browse All Available Doctors
- 📄 Dynamic Doctor Details Page
- 📅 Book Appointment System
- 🧾 User Dashboard with Booking Management
- ✏️ Update & Delete Appointment Feature
- 👤 User Profile Management
- 🔍 Search Doctors by Name
- 📱 Fully Responsive Design
- ⚡ Fast and Modern UI using Next.js & Tailwind CSS

---

## 🔑 Environment Variables

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000
```

## 📦 Installation & Setup

Clone the repository:


Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
